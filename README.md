# SARVESHTWR Learning Portal

**A Digital Learning Platform for School Students.**

SARVESHTWR Learning Portal provides organized, chapter-wise study materials for Classes 9–12 through a simple, responsive and user-friendly interface.

### Features
- Class-wise and subject-wise study materials
- Chapter-wise notes and learning resources
- Search and filter options
- Distraction-free reading mode
- Adjustable font size and print support
- Secure Admin Panel
- Rich Text Editor for managing study content
- Responsive design

### Technology Stack
HTML | CSS | JavaScript | Node.js | Express.js | MongoDB
